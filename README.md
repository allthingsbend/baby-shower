# Andie & Mitch's Baby Shower Website

A free baby shower RSVP website with a soft garden / wildflower / BBQ theme.

## Files

- `index.html` — main website content
- `styles.css` — styling/theme
- `script.js` — countdown, fade-in effects, RSVP button effect
- `assets/` — theme images

## What to update before publishing

Open `index.html` and update:

1. Time of the shower
2. Location/address
3. Registry link
4. Google Form embed

## Add the Google Form

1. Create a Google Form for RSVPs.
2. In Google Forms, click `Send`.
3. Click the embed icon: `<>`.
4. Copy the iframe code.
5. In `index.html`, replace the placeholder RSVP iframe with your Google Form iframe.

## Deploy

Upload the files to GitHub, then connect the GitHub repository to Netlify.
